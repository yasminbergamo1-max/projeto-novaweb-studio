#  Projeto NovaWeb Studio 

 Repositório inicial estruturado durante o treinamento de versionamento 

# Requisitos do Sistema

## Requisitos funcionais 

RF01 – Permitir o cadastro de clientes
RF02 – Permitir o cadastro de livros
RF03 – Permitir consultar e pesquisar livros pelo título, autor ou categoria
RF04 – Permitir atualizar e excluir informações de livros
RF05 – Permitir realizar a compra de livros
RF06 – Permitir visualizar o carrinho de compras
RF07 – Registrar os pedidos realizados pelos clientes
RF08 – Permitir que o usuário faça login no sistema

## Requistos não funcionais

RNF01 – O sistema deve possuir uma interface simples e intuitiva
RNF02 – O sistema deve responder as ações do usuário em poucos segundos
RNF03 – O código deve ser organizado e documentado
RNF04 – O projeto deve ser versionado utilizando Git e GitHub
RNF05 – O sistema deve ser compatível com os principais navegadores (Google Chrome, Microsoft Edge e Mozilla Firefox)
RNF06 – As informações dos usuários devem ser armazenadas com segurança
RNF07 – O sistema deve permitir fácil manutenção e atualização do código

# Projeto Livraria

## Descrição do Projeto

Este projeto consiste no desenvolvimento de um sistema de livraria, permitindo o cadastro e a consulta de livros, além da realização de compras pelos clientes.

# Parte 1 — Engenharia Reversa de Sintaxe

## XML

O XML é usado para organizar e armazenar informações. Ele permite criar tags próprias, como `livro`, `titulo` e `autor`. Por isso, ele se preocupa mais com os dados do que com a aparência na tela


## Markdown

O Markdown é simples, fácil e rápido de escrever. Ele é muito usado para criar arquivos como o `README.md`, que serve para explicar e documentar projetos em repositórios


## HTML

O HTML é usado para criar a estrutura de páginas da internet. Com ele podemos organizar títulos, textos, imagens, menus e produtos. Por isso, ele seria a base para criar a página de uma loja virtual

# O que difere um "Projeto de Software" de um "Script/Código isolado"? 

Projeto de software é um trabalho organizado com planejamento e várias etapas até a entrega. Script ou código isolado é apenas um programa simples para fazer uma tarefa específica 

 

# Ciclo de Vida Básico: 

Levantamento de Requisitos / Escopo: É a etapa em que são definidos os objetivos e as funções do sistema 

Desenvolvimento / Codificação: É quando o programador cria o código do sistema 

Testes / Qualidade: Serve para verificar se o sistema funciona corretamente e corrigir erros 

Entrega / Implantação: É quando o sistema é entregue e colocado para uso
